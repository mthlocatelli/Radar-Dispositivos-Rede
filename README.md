# Radar de Dispositivos da Rede

Projeto introdutorio em C++ que simula a disponibilidade de computadores de um laboratorio.

## Como funciona
- Informe de 1 a 10 dispositivos.
- Digite 1 para ativo e 0 para inativo.
- O programa lista os estados, conta ativos e inativos e calcula a porcentagem de disponibilidade.
- Exibe alerta quando existem dois ou mais dispositivos inativos.

## Como executar
Compile `Radar_Dispositivos_Rede.cpp` em um compilador C++ e execute o programa.

## Limite da simulacao
Os estados sao informados manualmente. O programa nao verifica IPs, nao envia ping e nao monitora uma rede real.
